- 经用户允许，只操作独立测试工程。在正版 Spine 3.8.99、4.0.33、4.1.17、4.2.43 中记录手动选中动作的保存结果，定位各版本的 active 状态字段。4.2 打开带选择状态的独立工程，确认首个动画选中；带 `--animate-mode` 启动时直接显示动画。
- 四个版本的候选工程均通过官方 CLI 回读比较；另对 23 个真实工程的独立副本逐个回读，选择状态改变后骨骼、皮肤、动画及导出数据保持一致。工程数据未知、记录匹配有歧义、回读失败或数据改变时不替换文件；用户已有工程不覆盖。
- 使用含 extra 的瑶瑶素材副本完整执行解包、导入、选择动画、回读校验：生成工程并选中 `animation`，导入副本不含 extra / extraSlot / extraConfig，原 JSON 字节保持一致，结果及日志包含 extra 仅网页生效的说明。
- Spine 3.8 不支持 `-e json` 简写，导出校验和二进制中转改用明确的 JSON 导出设置，禁用动画清理。

编辑器双击打开时仍可能进入设置模式，这是实际观察到的编辑器行为；切到动画模式即显示已选动作。网页打开按钮对 4.1+ 使用 `--animate-mode`。此功能不修改绑定姿态或烘焙 extra。

本机 Launcher 4.3.01 即使收到 `--no-reuse-instance` 仍可能转发给已有编辑器，因此不能保证已有窗口打开时切换版本或模式。关闭已有测试窗口后，4.2 的启动与首个动画显示已验证；程序不会擅自结束用户编辑器或修改全局偏好。
